# 🛒 Full Stack E-Commerce Platform

A production-ready **Full Stack E-Commerce Application** built using **Spring Boot, React.js, PostgreSQL, JWT Authentication, and REST APIs**.

This project demonstrates secure authentication, scalable backend architecture, responsive frontend design, and real-world e-commerce workflows.

# ⚙️ Backend Setup

Clone the repository:

```bash
git clone https://github.com/siva042004/ecommerce-api.git
```

Move to backend:

```bash
cd backend
```

Run application:

```bash
mvn spring-boot:run
```

Backend runs at:

```text
http://localhost:8080
```

Swagger:

```text
http://localhost:8080/swagger-ui/index.html
```

---

# 💻 Frontend Setup

Move to frontend:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run:

```bash
npm start
```

Frontend runs at:

```text
http://localhost:3000
```

Build:

```bash
npm run build
```
